# PhishGuard AI

Python을 활용한 피싱·스미싱 문자 위험 분석 프로젝트입니다.

## 1. 프로젝트 소개

PhishGuard AI는 문자 메시지에 포함된 의심 단어, 인터넷 주소, 긴급한 표현 및 위험 행동 유도 문구를 분석하여 위험 점수를 계산하고 사용자에게 주의 사항을 안내하는 프로그램입니다.

## 2. 주요 기능

- 문자 메시지 직접 입력
- 의심 단어 탐지
- 위험 요소별 점수 계산
- 위험 행동 유도 패턴 탐지
- 위험 점수에 따른 위험 수준 분류
- 가장 큰 위험 요소 표시
- 분석 요약 및 안전 수칙 안내

## 3. 위험 수준

| 점수 | 위험 수준 |
|---|---|
| 0~39점 | 낮음 |
| 40~79점 | 주의 |
| 80~100점 | 매우 위험 |

위험 점수는 프로그램에 설정된 규칙에 따라 계산됩니다. 낮은 점수가 반드시 안전한 문자를 의미하지는 않습니다.

## 4. 개발 환경

- Python
- Visual Studio Code
- Git 및 GitHub

## 5. 실행 방법

1. 프로젝트를 내려받거나 복제합니다.
2. 프로젝트 폴더에서 필요한 라이브러리를 설치합니다.
3. 터미널에서 프로그램을 실행합니다.

```bash
python main.py
```

필요한 라이브러리는 프로젝트의 `requirements.txt` 파일을 확인합니다.

## 6. 현재 구현 상태

현재 버전은 규칙 기반 분석 기능을 중심으로 구현되어 있습니다. OpenAI API를 통한 실제 AI 분석 기능은 API 사용량 및 크레딧 등의 조건에 따라 작동하지 않을 수 있습니다.

## 7. 향후 개선 계획

- 문자 분석 테스트 자동화
- 분석 기록 저장 기능
- 사용자 친화적인 GUI 제작
- 위험 탐지 규칙 개선
- 실제 AI 분석 기능 연동 검토

## 8. 주의 사항

이 프로그램은 문자 메시지의 위험 가능성을 판단하는 학습용 도구입니다. 분석 결과만으로 문자의 안전성을 확정할 수 없으며, 의심스러운 문자는 공식 홈페이지나 고객센터를 통해 별도로 확인해야 합니다.
